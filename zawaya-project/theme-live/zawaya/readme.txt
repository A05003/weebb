قالب زوايا المعالي — دليل سريع
================================

التثبيت
-------
1) لوحة ووردبريس ← المظهر ← قوالب ← أضف قالب ← رفع قالب ← اختر zawaya.zip ← تثبيت ← تفعيل.
2) عند التفعيل ينشئ القالب تلقائياً: الصفحات (من نحن، خدماتنا، مشاريعنا، المدونة، تواصل معنا)،
   القوائم، المشاريع السبعة بشعاراتها، الخدمات الأربع، وثلاث مقالات. لا يحذف أي شيء موجود.
   (إن احتجت إعادة تشغيله: أدوات ← زوايا: إعداد المحتوى)
3) الإعدادات ← الروابط الدائمة ← اختر "اسم المقالة" ← حفظ.

أين أعدّل ماذا؟
---------------
• النصوص، الأرقام، الهاتف، البريد، العنوان، واتساب، حسابات التواصل، فيديو الواجهة، صفحة من نحن، الفوتر:
  المظهر ← تخصيص ← إعدادات زوايا المعالي
• الشعار: المظهر ← تخصيص ← هوية الموقع ← الشعار
• القصور والمشاريع: القائمة الجانبية ← المشاريع والقصور (إضافة / تعديل / ترتيب بحقل "الترتيب")
• الخدمات: القائمة الجانبية ← الخدمات
• شركاء النجاح: القائمة الجانبية ← شركاء النجاح (يظهر القسم في الرئيسية عند إضافة شريك واحد على الأقل)
• المقالات: مقالات ← أضف جديد
• صورة أعلى أي صفحة: "الصورة البارزة" للصفحة. والعبارة تحت العنوان: "المقتطف".
• القوائم: المظهر ← القوائم
• رسائل نموذج التواصل: القائمة الجانبية ← رسائل التواصل (وتصل أيضاً على البريد)

ملاحظات
-------
• يُفضّل تثبيت إضافة WP Mail SMTP وربطها ببريد هوستنجر لضمان وصول رسائل النموذج إلى بريدك.
• الروابط القديمة مثل /project/?id=multaqa تُحوَّل تلقائياً إلى /project/multaqa/
• الخطوط والأيقونات مضمّنة داخل القالب (لا يعتمد على مواقع خارجية).

التعديل بالسحب والإفلات (Elementor) — جديد في الإصدار 1.1
--------------------------------------------------------
1) الإضافات ← أضف جديد ← ابحث عن Elementor ← تثبيت ← تفعيل (النسخة المجانية تكفي).
2) المظهر ← قوالب Elementor ← «إنشاء التصاميم الآن».
   يحوّل الصفحات الخمس (الرئيسية، من نحن، خدماتنا، مشاريعنا، تواصل معنا) إلى تصاميم Elementor
   بنفس الشكل الحالي، ويحفظ نسخة من كل صفحة وكل قسم في: القوالب ← القوالب المحفوظة.
3) افتح أي صفحة واضغط «تحرير بواسطة Elementor»، وعدّل أي نص أو صورة أو لون أو ترتيب.

• عناصر زوايا الخاصة في لوحة Elementor تحت تصنيف «زوايا المعالي»:
  بانر الصفحة، بطاقات قلّابة متحركة، المشاريع والقصور، شركاء النجاح، نموذج التواصل.
• ألوان الهوية في: Elementor ← إعدادات الموقع ← الألوان العامة («زوايا: …») وتعمل مع الوضع الليلي.
• الهيدر والفوتر يبقيان من القالب (المظهر ← تخصيص / القوائم).
• إعادة الضغط على «إنشاء التصاميم» تستبدل تعديلاتك على هذه الصفحات (مع حفظ نسخة احتياطية).
